# SqlIdentityDefinition

Parsed identity generation mode, start and signed increment.

Namespace: `Assimalign.Cohesion.Database.Sql.Language`.

## Signature

```csharp
public sealed class SqlIdentityDefinition
{
    public bool IsAlways { get; }
    public long Start { get; }
    public long Increment { get; }
    public IReadOnlyList<SqlSequenceOption> Options { get; }
}
```

## Behavior and exceptions

Construction is internal; read [SqlColumnDefinition.Identity](sql-column-definition.md) from
CREATE TABLE or ALTER ADD. GENERATED ALWAYS and SQL Server IDENTITY map to IsAlways true;
GENERATED BY DEFAULT maps to false. Start retains explicit START or a written directional
MINVALUE/MAXVALUE; without either, it defaults to 1 ascending or -1 descending. Increment
defaults to 1. Identity makes the parsed column nonnullable.

Options retains explicit sequence options in source order: START, INCREMENT, MINVALUE,
MAXVALUE, CACHE and CYCLE, including NO forms. Execution resolves effective bounds/defaults
onto the owned sequence. SERIAL/SERIAL4, BIGSERIAL/SERIAL8 and SMALLSERIAL/SERIAL2 map to
BY DEFAULT identity definitions of INTEGER, BIGINT and SMALLINT respectively.

Accessors do not validate or execute. Malformed options and conflicting explicit NULL declarations
are `CS00003` parser diagnostics. Engine planning rejects a non-built-in integer, zero increment,
out-of-bounds start, DEFAULT conflict or second identity with `CS03025`. START/INCREMENT obey
[direction-dependent bounds](../../../../database/sql/language/clauses/identity.md).

## Example

```csharp
var statement = (SqlQueryStatement)new SqlQueryParser().Parse(
    "CREATE TABLE ids (id BIGINT GENERATED BY DEFAULT AS IDENTITY (START -8 INCREMENT -2));");
var column = ((SqlCreateTableExpression)statement.SqlExpression).Columns[0];
Console.WriteLine(column.Identity!.IsAlways); // False
Console.WriteLine(column.Identity.Start);     // -8
Console.WriteLine(column.Identity.Increment); // -2
Console.WriteLine(column.IsNullable);         // False
```

Execution generates -8, -10, -12 and so on for omitted identity values. A positive START with this
negative increment needs an explicit MAXVALUE that includes it; default descending bounds end at -1.
